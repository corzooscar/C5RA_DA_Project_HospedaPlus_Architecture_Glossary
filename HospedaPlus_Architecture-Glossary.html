HospedaPlus Revenue: Glosario Visual de Arquitectura

Guía completa de servicios, roles y justificaciones técnicas por capa

Capa 1: Inputs and Edge (Entradas y Borde)

Amazon Route 53

DNS

Rol en la infraestructura: Es la guía telefónica de Internet. Traduce el nombre de dominio legible (ej. api.hospedaplus.com) a la dirección IP del Application Load Balancer. Es el primer punto de contacto para los huéspedes y el Channel Manager.

Importancia: Crítica Complejidad: Baja

Ventajas vs. Alternativas (Cloudflare): Integración nativa con IAM y ALB, enrutamiento por latencia y SLA del 100%.

Analogía: Es el GPS que te dice a qué dirección física (IP) debe ir tu carta (petición HTTP).

AWS WAF

Web Application Firewall

Rol en la infraestructura: Es el guardaespaldas de la API. Filtra el tráfico malicioso (SQL injection, XSS, bots) antes de que llegue al ALB, protegiendo el sistema de reservas en tiempo real.

Importancia: Crítica Complejidad: Media

Ventajas vs. Alternativas (Cloudflare WAF): Nativo de AWS, se integra con CloudWatch para alarmas y no requiere gestionar servidores.

Analogía: Es el detector de metales en la entrada de un aeropuerto: deja pasar a los pasajeros legítimos, pero bloquea a quien trae armas.

Application Load Balancer

ALB

Rol en la infraestructura: Es el director de tráfico. Reparte las peticiones de reserva entre las múltiples tareas de FastAPI en ECS Fargate, distribuyéndolas en 2 Zonas de Disponibilidad. Si una tarea falla, deja de enviarle tráfico (Health Checks).

Importancia: Alta Complejidad: Baja

Ventajas vs. Alternativas (Nginx): Servicio gestionado, escala automáticamente y no es un punto único de fallo.

Analogía: Es el guardia de tráfico que dirige los autos al carril disponible para evitar embotellamientos.

NAT + Internet Gateway

Red VPC

Rol en la infraestructura: El Internet Gateway permite la entrada desde Internet al ALB. El NAT Gateway permite que los recursos en subredes privadas (FastAPI, Spark) salgan a Internet sin ser accesibles directamente desde fuera.

Importancia: Crítica Complejidad: Media

Ventajas vs. Alternativas: Única forma segura y estándar de dar salida a Internet a subredes privadas en AWS.

Analogía: El Internet Gateway es la puerta principal; el NAT Gateway es la puerta trasera por la que sale el personal de servicio sin que los visitantes entren por ahí.

Amazon ECR + GitHub Actions

CI/CD y Registro

Rol en la infraestructura: Es la fábrica y el almacén de contenedores. GitHub Actions empaqueta el código en imágenes Docker y las sube a ECR. Luego, ECS descarga estas imágenes para ejecutarlas.

Importancia: Media Complejidad: Baja-Media

Ventajas vs. Alternativas (Docker Hub): ECR es privado por defecto, sin límites de pulls, e integrado con IAM.

Analogía: GitHub Actions es la cocina donde se preparan los platos (código); ECR es la nevera donde se guardan hasta que el restaurante (ECS) los pide.

Capa 2: Speed Layer (Capa de Velocidad)

ECS Fargate · FastAPI

API en Tiempo Real

Rol en la infraestructura: Es el cerebro de las reservas en tiempo real. Recibe peticiones, aplica reglas de negocio (RN-03, RN-04, RN-07: límites de sobreventa y penalizaciones) y escribe en RDS PostgreSQL en una transacción atómica. Debe responder en milisegundos.

Importancia: Crítica Complejidad: Media

Ventajas vs. Alternativas (EC2, Lambda): Fargate elimina la gestión de servidores. FastAPI es asíncrono (ASGI) y más rápido. Lambda tiene límite de 15 min.

Analogía: Es un mesero extremadamente rápido que toma el pedido, verifica disponibilidad y confirma la reserva en el acto.

RabbitMQ

Message Broker

Rol en la infraestructura: Es la tubería de eventos del Channel Manager. Recibe eventos de reserva (F2) y los encola de forma durable (con ACK). Evita perder reservas si el consumidor está saturado. También es el broker de Celery para Airflow.

Importancia: Alta Complejidad: Media

Ventajas vs. Alternativas (SQS, Kafka): Ofrece enrutamiento flexible. SQS es serverless pero menos flexible. Kafka está sobredimensionado para este caso.

Analogía: Es una oficina de correos que recibe y clasifica las cartas (eventos) para que el cartero (Consumer) las entregue en orden.

ECS Fargate · Consumer

Consumidor de Eventos

Rol en la infraestructura: Es el aplicador de eventos en tiempo real. Lee mensajes de RabbitMQ, actualiza inventario en RDS (misma transacción atómica que FastAPI para evitar doble reserva) y copia el evento crudo a S3 Bronze.

Importancia: Crítica Complejidad: Media

Ventajas vs. Alternativas (Lambda): Fargate permite procesos de larga duración y conexiones persistentes a RabbitMQ, algo que Lambda no soporta bien.

Analogía: Es el cartero que lee cada carta, actualiza el inventario en el sistema central y archiva una copia en el sótano (S3 Bronze).

Amazon RDS PostgreSQL

Multi-AZ

Rol en la infraestructura: Es la fuente de verdad operativa. Almacena el motor de reservas (F3), inventario, tarifas y límites de sobreventa para los 28 hoteles. Garantiza ACID para que no se venda una habitación dos veces.

Importancia: Crítica Complejidad: Media

Ventajas vs. Alternativas (Aurora, DynamoDB): RDS es más económico que Aurora. DynamoDB no soporta transacciones ACID multi-tabla ni joins.

Analogía: Es la caja registradora central blindada: debe ser confiable, precisa y no puede perder ninguna transacción.

Capa 3: Batch Layer (Capa Diaria)

Airflow con Celery

Orquestador Batch

Rol en la infraestructura: Es el director de orquesta. Programa las tareas diarias: extraer datos de APIs (Lambda), copiar archivos a S3, lanzar Jobs de Spark, ejecutar el Crawler de Glue y orquestar el retorno de precios a RDS.

Importancia: Crítica Complejidad: Alta

Ventajas vs. Alternativas (MWAA): Airflow en EC2 es $499/mes más barato que MWAA. Step Functions está atado a AWS y es menos flexible para DAGs complejos.

Analogía: Es el director de una orquesta que indica cuándo debe tocar cada músico (worker) para que la sinfonía (pipeline) suene perfecta.

Spark en Fargate Spot

Procesamiento Distribuido

Rol en la infraestructura: Es la refinería de datos. Ejecuta los Jobs 1 (Bronze a Silver: limpieza, pseudonimización), Job 2 (Silver a Gold: ADR, RevPAR, pickup) y Job 3 (Reglas de negocio: precios dinámicos que retornan a RDS).

Importancia: Crítica Complejidad: Alta

Ventajas vs. Alternativas (Glue, Databricks): Fargate Spot ahorra ~$11.90/mes. Glue es más caro. Databricks cobra licencias por DBU.

Analogía: Es una fábrica con miles de trabajadores temporales (Spot) que procesan la materia prima y la convierten en productos terminados (KPIs).

AWS Lambda

Extractor Serverless

Rol en la infraestructura: Es el extractor de APIs externas. Airflow invoca funciones Lambda para llamar a las APIs F5 (Reseñas), F6 (Eventos) y F7 (Divisas), extraer el JSON crudo y depositarlo en S3 Bronze.

Importancia: Alta Complejidad: Baja

Ventajas vs. Alternativas (EC2): Sin servidores, pago por ejecución, ideal para tareas intermitentes. EC2 estaría encendido 24/7 sin necesidad.

Analogía: Es un taxi: lo llamas cuando lo necesitas, haces el viaje (extracción) y lo despides. No pagas por tenerlo estacionado.

Shared Backend (EC2 + EBS)

Host Compartido

Rol en la infraestructura: Es el hogar de Airflow y RabbitMQ. Una sola instancia EC2 t3.large con un volumen EBS gp3 de 100 GB aloja el scheduler de Airflow y el broker RabbitMQ, ahorrando $499/mes frente a MWAA + Amazon MQ.

Importancia: Alta Complejidad: Media

Ventajas vs. Alternativas (MWAA + MQ): Ahorro masivo de costos. Se asume el riesgo de ser un punto único de fallo (SPOF).

Analogía: Es el edificio de oficinas donde trabajan el director de orquesta (Airflow) y la oficina de correos (RabbitMQ).

Seed and Simulators

ECS Fargate

Rol en la infraestructura: Es el generador de datos sintéticos. Puebla el sistema con datos de prueba versionados para que los desarrolladores y el pipeline puedan probarse sin depender de datos reales de producción.

Importancia: Media Complejidad: Baja

Ventajas vs. Alternativas (Datos reales): Evita exponer datos sensibles de huéspedes en entornos de desarrollo y permite probar escenarios extremos.

Analogía: Es el equipo de actores que simulan ser clientes para que el restaurante (sistema) practique antes de la apertura real.

Capa 4: Data Lake and Catalog

Amazon S3 · Medallion

Bronze, Silver, Gold

Rol en la infraestructura: Es el almacén central de datos (Data Lake). Bronze: JSON crudo de Lambda y CSV de Airflow. Silver: Datos limpios, deduplicados y pseudonimizados en Parquet. Gold: Esquema estrella con KPIs listos para Athena y QuickSight.

Importancia: Crítica Complejidad: Baja

Ventajas vs. Alternativas (HDFS, Azure Blob): S3 es gestionado, duradero (11 nueves) y no requiere clústeres.

Analogía: Es un almacén infinito de cajas: Bronze son cajas sin abrir, Silver son cajas organizadas, Gold son cajas con productos listos para vender.

AWS Glue Crawler

Rastreador de Esquemas

Rol en la infraestructura: Es el bibliotecario. Escanea la capa Gold de S3 después de cada ejecución de Spark, descubre nuevas tablas y particiones, y actualiza el Glue Data Catalog.

Importancia: Media Complejidad: Baja

Ventajas vs. Alternativas (Scripts manuales): Automatiza la catalogación y detecta cambios de esquema sin intervención humana.

Analogía: Es el bibliotecario que escanea libros nuevos y actualiza el índice de la biblioteca.

AWS Glue Data Catalog

Metastore Central

Rol en la infraestructura: Es el diccionario de datos. Almacena la definición de cada tabla y columna en S3, permitiendo que Athena y Spark sepan qué están leyendo y cómo consultarlo.

Importancia: Alta Complejidad: Baja-Media

Ventajas vs. Alternativas (Hive Metastore): Serverless, integrado con Athena y sin coste adicional por consulta.

Analogía: Es el índice de una biblioteca: sin él, no sabrías qué libros tienes ni dónde encontrarlos.

Amazon Athena

Consultas SQL Serverless

Rol en la infraestructura: Es el motor de consultas analíticas. Lee la capa Gold de S3 a través del Glue Catalog y devuelve los datos a QuickSight. Pagas solo por TB escaneado ($5/TB).

Importancia: Alta Complejidad: Baja

Ventajas vs. Alternativas (Redshift, Snowflake): Sin coste fijo de clúster inactivo. Para 0.2 TB/mes, cuesta solo $1.00.

Analogía: Es un buscador que lee libros directamente en los estantes sin tener que moverlos a una mesa.

Capa 5: Analytics and Staging

Amazon QuickSight

Business Intelligence

Rol en la infraestructura: Es la capa de visualización. Consume los datos de Athena y presenta dashboards de ocupación, ADR, RevPAR, pickup y reputación para los gerentes de hotel y revenue managers.

Importancia: Alta Complejidad: Baja

Ventajas vs. Alternativas (Power BI): Lee Athena directamente sin Data Gateway. Más barato: $36/mes (1 Autor + 4 Lectores) vs. $70/mes de Power BI Pro.

Analogía: Es el tablero de un automóvil que muestra velocidad, gasolina y temperatura de forma visual y comprensible.

Staging VPC

Entorno de Pruebas

Rol en la infraestructura: Es el campo de pruebas. Permite probar nuevas versiones de FastAPI, Spark o cambios en RDS sin afectar a los huéspedes reales. Corre solo en horario laboral (~220 h/mes) para ahorrar costos.

Importancia: Media Complejidad: Media

Ventajas vs. Alternativas (Probar en producción): Evita caídas del sistema real y permite experimentar con seguridad.

Analogía: Es el simulador de vuelo para pilotos: practicas maniobras riesgosas sin poner en peligro a los pasajeros reales.

Capa 6: Security and Observability

AWS IAM

Identity and Access Management

Rol en la infraestructura: Es el guardia de seguridad. Define roles de privilegio mínimo: Lambda solo puede escribir en S3 Bronze, Spark solo puede leer de S3 y escribir en RDS. Sin IAM, los servicios no podrían comunicarse de forma segura.

Importancia: Crítica Complejidad: Media

Ventajas vs. Alternativas (Okta): Gratuito con AWS, nativo para todos los servicios, sin mantenimiento.

Analogía: Es el sistema de tarjetas de acceso de la empresa: cada empleado solo puede entrar a su oficina.

AWS KMS

Key Management Service

Rol en la infraestructura: Es el cerrajero. Cifra los datos en reposo en S3, RDS y los secretos. Garantiza que si alguien roba un disco físico de AWS, no pueda leer los datos.

Importancia: Alta Complejidad: Baja

Ventajas vs. Alternativas (Cifrado manual): Totalmente gestionado, rota claves automáticamente, se integra con CloudTrail.

Analogía: Es la caja fuerte donde se guardan las llaves de la empresa.

AWS Secrets Manager

Gestión de Credenciales

Rol en la infraestructura: Es el guardián de las contraseñas. Guarda las credenciales de RDS, RabbitMQ y APIs externas fuera del código fuente. FastAPI y Airflow las leen en tiempo de ejecución.

Importancia: Alta Complejidad: Baja

Ventajas vs. Alternativas (Variables de entorno): Rota credenciales automáticamente, evita fugas de secretos en el código.

Analogía: Es la caja de seguridad donde se guardan las llaves de acceso, en lugar de dejarlas debajo del felpudo.

Amazon CloudWatch

Monitoreo y Alarmas

Rol en la infraestructura: Es el sistema de observabilidad. Recopila logs de Lambda, Airflow, Spark y FastAPI. Monitorea la latencia de la API (RNF-01) y dispara alarmas si algo falla (ej. si el Consumer se detiene).

Importancia: Alta Complejidad: Baja-Media

Ventajas vs. Alternativas (Datadog): Nativo de AWS, sin coste de integración, cubre logs/métricas/alarmas en un solo servicio.

Analogía: Son las cámaras de seguridad y el sistema de alarmas de la empresa.

AWS CloudTrail

Auditoría

Rol en la infraestructura: Es el registro notarial. Guarda un historial de quién hizo qué en la cuenta (quién creó un bucket, quién modificó un rol de IAM). Esencial para cumplimiento y seguridad.

Importancia: Alta Complejidad: Baja

Ventajas vs. Alternativas (Logs manuales): Automático, inmutable, integrado con CloudWatch para alertas.

Analogía: Es el libro de actas de una empresa: registra cada decisión y acción importante para futuras auditorías.
