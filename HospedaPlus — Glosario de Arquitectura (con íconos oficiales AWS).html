Capa 1: Inputs and Edge (Entradas y Borde)

Amazon Route 53

DNS
RF-05: API Disponibilidad RNF-04: 99.9% Disponibilidad Tema 6: AWS Networking
Concepto

Servicio DNS (Domain Name System) gestionado de AWS. Un DNS traduce nombres de dominio legibles por personas (como api.hospedaplus.com) en direcciones IP que las máquinas usan para encontrarse en la red. Route 53 además registra dominios y hace health checks para enrutar solo hacia destinos sanos.

Rol clave: Es el primer punto de contacto. Traduce el dominio legible (api.hospedaplus.com) a la IP del ALB. Garantiza que el Channel Manager y los huéspedes lleguen a la API de disponibilidad.

Importancia: Crítica Complejidad: Baja

Ventajas vs. Alternativas: Enrutamiento por latencia, SLA del 100%, integración nativa con IAM.

Costo: $0.90/mes
Analogía: Es el GPS que traduce el nombre de la calle a coordenadas exactas.

AWS WAF

Web Application Firewall
RNF-06: Seguridad Tema 6: AWS Networking
Concepto

Un Web Application Firewall inspecciona las peticiones HTTP/HTTPS (capa 7) antes de que lleguen a la aplicación y las permite, bloquea o cuenta según reglas. A diferencia de un firewall de red, entiende el contenido de la petición: URLs, cabeceras, cuerpo, IP de origen y frecuencia (rate limiting).

Rol clave: Es el guardaespaldas perimetral. Filtra tráfico malicioso (SQLi, XSS, bots) antes de que toque el ALB, protegiendo la API en tiempo real y los datos de huéspedes.

Importancia: Crítica Complejidad: Media

Ventajas vs. Alternativas: Reglas gestionadas por AWS, integración con CloudWatch para alertas.

Costo: $23.54/mes
Analogía: Es el detector de metales en un aeropuerto: bloquea amenazas, deja pasar pasajeros.

Application Load Balancer

ALB
RNF-04: 99.9% Disponibilidad RF-05: API Disponibilidad Tema 9: Fargate + ALB
Concepto

Un balanceador de carga distribuye el tráfico entrante entre varios destinos (contenedores, instancias) para que ninguno se sature y para que la caída de uno no tumbe el servicio. El ALB opera en capa 7: puede enrutar según la ruta o el host de la URL y comprueba periódicamente la salud de cada destino.

Rol clave: Es el director de tráfico. Reparte las peticiones entre las tareas de FastAPI en 2 AZs y ejecuta health checks. Si un contenedor falla, el ALB lo retira del pool.

Importancia: Crítica Complejidad: Baja

Ventajas vs. Alternativas: Servicio gestionado, escalado automático, elimina SPOF.

Costo: $18.77/mes
Analogía: Es el guardia de tráfico que dirige los autos al carril con menos congestión.

NAT + Internet Gateway

Red VPC
Tema 6: AWS Networking (VPC)
Concepto

Una VPC (Virtual Private Cloud) es una red privada aislada dentro de AWS, dividida en subredes públicas y privadas. El Internet Gateway conecta la VPC con Internet en ambos sentidos; el NAT Gateway (Network Address Translation) permite que recursos de subredes privadas salgan a Internet sin poder recibir conexiones iniciadas desde fuera.

Rol clave: El Internet Gateway permite la entrada al ALB. El NAT Gateway da salida a Internet a los servicios en subredes privadas (FastAPI, Spark, Lambda) sin exponerlos directamente.

Importancia: Crítica Complejidad: Media

Ventajas vs. Alternativas: Aislamiento de red estándar en AWS. NAT Gateway es gestionado y altamente disponible. En esta estimación se usó 1 NAT Gateway (no 2), por lo que la subred privada queda sin redundancia entre zonas de disponibilidad si esa AZ falla — un trade-off de costo documentado, no un descuido.

Costo: $35.10/mes (VPC: 1 NAT Gateway, 1 AZ)
Analogía: El Internet Gateway es la puerta principal; el NAT es la puerta trasera de servicio.

Public IPv4 + Data Transfer

Direccionamiento y Salida de Datos
Tema 6: AWS Networking
Concepto

Una dirección IPv4 pública es un identificador alcanzable desde Internet; desde febrero de 2024 AWS cobra cada una por hora, esté en uso o no. La transferencia de datos (data transfer out) es el volumen que sale de AWS hacia Internet; la entrada suele ser gratuita, la salida se factura por GB.

Rol clave: Son los costos de red que se olvidan con facilidad. Cada IPv4 pública (2 del ALB, 1 del NAT) se cobra por hora desde 2024, y cada GB que sale de la VPC hacia Internet (respuestas de la API, consultas externas) tiene un cargo de transferencia saliente.

Importancia: Media Complejidad: Baja

Ventajas vs. Alternativas: No hay forma de evitarlos sin sacrificar disponibilidad pública; se incluyen explícitamente para que la estimación no subestime el costo real (penalización CT-05 por supuestos no verificables).

Costo: $10.95/mes (3 IPs) + $4.50/mes (50 GB salientes) = $15.45/mes
Analogía: Es el peaje de la autopista: cada placa (IP) y cada kilómetro recorrido (GB) se cobra por separado.

Amazon ECR + GitHub Actions

CI/CD y Registro
Tema 8: ECR + ECS Tema 17: CI/CD Aplicaciones CT-04: Pipeline bloquea merge
Concepto

Un registro de contenedores almacena y versiona imágenes Docker para que los servicios de cómputo las descarguen al desplegar. ECR (Elastic Container Registry) es el registro privado de AWS. GitHub Actions es una plataforma de CI/CD: ejecuta automáticamente pruebas, build y despliegue cada vez que hay cambios en el repositorio.

Rol clave: Fábrica de contenedores. GitHub Actions empaqueta el código en imágenes Docker y las sube a ECR. ECS descarga estas imágenes para ejecutar FastAPI, Spark y RabbitMQ.

Importancia: Media Complejidad: Baja-Media

Ventajas vs. Alternativas: ECR privado por defecto, sin límites de pulls, integrado con IAM.

Costo: $0.50/mes
Analogía: GitHub Actions es la cocina; ECR es la nevera donde se guardan los platos listos.

Capa 2: Speed Layer (Capa de Velocidad)

ECS Fargate · FastAPI

API en Tiempo Real
RF-01 al RF-07 RN-03, RN-04, RN-07 (Sobreventa/Cancelación) RNF-01: Latencia p95 ≤ 250ms RNF-02: Consistencia Temas 1, 2, 8, 9
Concepto

ECS (Elastic Container Service) orquesta contenedores; Fargate es su modo serverless: defines CPU y memoria por tarea y AWS gestiona los servidores por debajo. FastAPI es un framework web de Python, asíncrono y de alto rendimiento, que genera documentación OpenAPI automáticamente a partir del código.

Rol clave: Es el cerebro de las reservas. Aplica reglas de negocio en milisegundos (límites de sobreventa, penalizaciones). Escribe en RDS en una transacción atómica para evitar sobreventa (CA-08: 50 solicitudes concurrentes).

Importancia: Crítica Complejidad: Media

Ventajas vs. Alternativas (Lambda): Fargate permite conexiones persistentes y procesos largos. FastAPI es asíncrono y rápido.

Costo: $72.08/mes
Analogía: Es un mesero ultra rápido que verifica disponibilidad y confirma la reserva en el acto.

RabbitMQ

Message Broker
RNF-05: Ningún evento perdido CA-09: Eventos fuera de orden Tema 10: RabbitMQ
Concepto

Un message broker es un intermediario que recibe mensajes de productores, los guarda en colas y los entrega a consumidores, desacoplando a quien envía de quien procesa. RabbitMQ es un broker open source basado en AMQP: soporta exchanges, enrutamiento por claves, colas durables y confirmaciones (ACK) para no perder mensajes.

Rol clave: Es la tubería de eventos. Recibe eventos del Channel Manager (F2) y los encola durablemente (con ACK). Evita la pérdida de reservas si el consumidor se satura. Usa 2 vhosts (reservas y Airflow) para ahorrar costos.

Importancia: Alta Complejidad: Media

Ventajas vs. Alternativas (SQS): Enrutamiento flexible, persistencia de mensajes, ideal para eventos fuera de orden.

Costo: incluido en el host EC2 compartido (ver tarjeta "Shared Backend" en Capa 3) — no se factura aparte, RabbitMQ no corre en Fargate
Analogía: Es la oficina de correos que clasifica y guarda las cartas hasta que el cartero las procesa.

ECS Fargate · Consumer

Consumidor de Eventos
RF-01, RF-07 RN-08: Duplicados entre canales CA-09: Out-of-order events Temas 8, 9
Concepto

Un consumidor (consumer) es un proceso de larga duración que escucha una cola, toma cada mensaje, lo procesa y confirma (ACK) que terminó; si falla antes de confirmar, el broker vuelve a entregar el mensaje. Ejecutarlo en Fargate permite mantener la conexión abierta de forma continua sin administrar servidores.

Rol clave: Es el aplicador de eventos. Lee mensajes de RabbitMQ, aplica cambios de inventario en RDS (misma transacción atómica que FastAPI) y copia el evento crudo a S3 Bronze para auditoría.

Importancia: Crítica Complejidad: Media

Ventajas vs. Alternativas (Lambda): Conexiones persistentes a RabbitMQ, procesos de larga duración.

Costo: $36.04/mes
Analogía: Es el cartero que lee, actualiza el inventario y archiva una copia en el sótano.

Amazon RDS PostgreSQL

Multi-AZ
RF-02: Inventario disponible RNF-02: Consistencia CA-08: Cero doble venta Tema 7: S3 + RDS
Concepto

RDS (Relational Database Service) es una base de datos relacional gestionada: AWS se encarga de backups, parches y réplicas. PostgreSQL es el motor, con transacciones ACID (atómicas, consistentes, aisladas y durables). Multi-AZ mantiene una réplica síncrona en otra zona de disponibilidad que toma el control automáticamente si la principal falla.

Rol clave: Es la fuente de verdad operativa. Almacena inventario, tarifas, reservas y límites de sobreventa para los 28 hoteles. Garantiza ACID para evitar vender la misma habitación dos veces.

Importancia: Crítica Complejidad: Media

Ventajas vs. Alternativas (DynamoDB): Soporta transacciones ACID multi-tabla y joins, esenciales para consultas de disponibilidad.

Costo: $117.17/mes
Analogía: Es la caja registradora blindada que nunca pierde una transacción.

Capa 3: Batch Layer (Capa Diaria)

Airflow con Celery

Orquestador Batch
RN-05: Precios diarios RNF-03: Precios antes de las 06:00 Temas 11, 12
Concepto

Apache Airflow es un orquestador de flujos de trabajo: define pipelines como DAGs (grafos dirigidos acíclicos) en Python, con dependencias, horarios y reintentos. El CeleryExecutor reparte las tareas entre varios workers usando un broker de mensajes (aquí RabbitMQ) como cola.

Rol clave: Es el director de orquesta. Programa las tareas diarias: extracción de APIs (Lambda), copia a S3, Jobs de Spark, Crawler de Glue y el retorno de precios a RDS. Celery distribuye las tareas.

Importancia: Crítica Complejidad: Alta

Ventajas vs. Alternativas (MWAA): Airflow en EC2 ahorra frente a MWAA + Amazon MQ gestionados (ver comparativa en la tarjeta "Shared Backend").

Costo: incluido en el host EC2 compartido (ver tarjeta "Shared Backend" en esta misma capa) — no se factura aparte
Analogía: Es el director de orquesta que coordina a todos los músicos (workers) para que la sinfonía suene perfecta.

Spark en Fargate Spot

Procesamiento Distribuido
RN-01: ADR, RevPAR RN-10: Reputación RN-11: Seudonimización Temas 13, 14, 15, 16
Concepto

Apache Spark es un motor de procesamiento distribuido que divide grandes volúmenes de datos en particiones y los procesa en paralelo, en memoria. Spot es capacidad sobrante de AWS vendida con gran descuento, a cambio de que AWS pueda reclamarla con 2 minutos de aviso; por eso encaja con trabajos batch tolerantes a interrupciones.

Rol clave: Es la refinería de datos. Job 1 (Bronze->Silver: limpieza), Job 2 (Silver->Gold: ADR, RevPAR, pickup, reputación), Job 3 (Precios dinámicos -> RDS).

Importancia: Crítica Complejidad: Alta

Ventajas vs. Alternativas (Glue): Fargate Spot ahorra ~70% frente a On-Demand. Control total sobre versiones de librerías.

Costo: $5.57/mes (On-Demand real: $17.47/mes — la AWS Pricing Calculator no modela tarifas Spot para Fargate directamente, así que se calculó On-Demand y se aplicó el 70% de descuento típico de Spot manualmente)
Analogía: Es una fábrica con miles de trabajadores temporales (Spot) procesando materia prima en productos terminados.

AWS Lambda

Extractor Serverless
F5, F6, F7: Extracción APIs Tema 5: AWS Fundamentos
Concepto

Lambda es cómputo serverless orientado a eventos: subes una función y AWS la ejecuta solo cuando se invoca, escalando automáticamente. Se paga por número de invocaciones y por tiempo de ejecución (GB-segundo), con un límite de 15 minutos por ejecución.

Rol clave: Es el extractor de APIs externas. Airflow invoca funciones Lambda para llamar a las APIs de Reseñas, Eventos y Divisas, extrayendo el JSON crudo y depositándolo en S3 Bronze.

Importancia: Alta Complejidad: Baja

Ventajas vs. Alternativas (EC2): Sin servidores, pago por ejecución, ideal para tareas intermitentes.

Costo: $0.00 (Free Tier)
Analogía: Es un taxi: lo llamas cuando lo necesitas, haces el viaje y lo despides.

Shared Backend (EC2 + EBS)

Host Compartido
Tema 6: AWS Networking + EC2
Concepto

EC2 (Elastic Compute Cloud) ofrece máquinas virtuales donde tú controlas el sistema operativo y el software instalado. EBS (Elastic Block Store) es el disco persistente conectado a esa máquina; gp3 es el tipo SSD de propósito general. Un único punto de falla (SPOF) es un componente cuya caída detiene todo lo que depende de él.

Rol clave: Es el hogar de Airflow y RabbitMQ. Una sola instancia t3.large (100 GB EBS gp3) aloja el scheduler de Airflow y el broker RabbitMQ a la vez. Este es el único lugar donde se factura el costo de ambos — las tarjetas de RabbitMQ y Airflow lo referencian, no lo duplican.

Importancia: Alta Complejidad: Media

Ventajas vs. Alternativas (MWAA $357.70 + Amazon MQ $210.24): Ahorra cerca de $499/mes frente a los dos servicios gestionados por separado. La contrapartida es un único punto de falla para dos funciones críticas a la vez (RNF-05: ningún evento perdido; RNF-03: precios antes de las 06:00) — si este EC2 cae, ambas garantías se pierden simultáneamente. Es un riesgo aceptado conscientemente por costo, no un descuido, y debe quedar documentado como tal en el ADR correspondiente.

Costo: $68.74/mes (único cargo real: EC2 t3.large + EBS 100GB)
Analogía: Es el edificio de oficinas donde trabajan el director de orquesta y la oficina de correos — si el edificio se incendia, ambos dejan de operar a la vez.

Capa 4: Data Lake and Catalog

Amazon S3 · Medallion

Bronze, Silver, Gold
RF-09: Modelo Analítico RN-11: Sin datos personales en Silver/Gold Tema 7: S3, Tema 20: Data Lake
Concepto

S3 (Simple Storage Service) es almacenamiento de objetos: guarda archivos de cualquier tipo en buckets, con durabilidad de 11 nueves. La arquitectura Medallion organiza un Data Lake en capas de calidad creciente: Bronze (datos crudos), Silver (limpios y validados) y Gold (agregados y modelados para análisis).

Rol clave: Es el almacén central (Data Lake). Bronze (JSON/CSV crudo), Silver (limpio, seudonimizado, Parquet), Gold (Esquema estrella con KPIs listos para Athena).

Importancia: Crítica Complejidad: Baja

Ventajas vs. Alternativas (HDFS): Durabilidad 11 nueves, escalabilidad infinita, sin gestión de clústeres.

Costo: $4.30/mes
Analogía: Es un almacén infinito: Bronze son cajas sin abrir, Silver organizadas, Gold listas para vender.

AWS Glue Crawler

Rastreador de Esquemas
RF-09: Modelo Analítico Tema 20: Arquitectura + Power BI
Concepto

AWS Glue es el servicio de integración de datos (ETL) serverless de AWS. Un crawler recorre una ubicación de datos (por ejemplo, un prefijo de S3), infiere el esquema y las particiones de los archivos y registra o actualiza las tablas en el Data Catalog. Se cobra por DPU-hora (Data Processing Unit) con mínimo facturable de 10 minutos por ejecución.

Rol clave: Es el bibliotecario. Escanea la capa Gold, descubre nuevas tablas y particiones, y actualiza el Glue Data Catalog para que Athena sepa qué consultar.

Importancia: Media Complejidad: Baja

Ventajas vs. Alternativas (Scripts manuales): Automatiza la catalogación y detecta cambios de esquema.

Costo: $4.40/mes (2 DPU × 10 min × $0.44/DPU-h × 30 runs; Data Catalog dentro del Free Tier) — la AWS Pricing Calculator no permite definir 30 ejecuciones mensuales de 10 min, así que este valor se calculó manualmente
Analogía: Es el bibliotecario que escanea libros nuevos y actualiza el índice.

AWS Glue Data Catalog

Metastore Central
RF-09: Modelo Analítico Tema 20: Data Lake
Concepto

Un catálogo de datos (metastore) guarda los metadatos de las tablas: nombre, columnas, tipos, formato y ubicación en S3. No contiene los datos, solo su descripción, y permite que motores como Athena o Spark consulten archivos en S3 como si fueran tablas. Es compatible con el Hive Metastore.

Rol clave: Es el diccionario de datos. Almacena metadatos de las tablas en S3, permitiendo que Athena y Spark las lean sin mover los datos.

Importancia: Alta Complejidad: Baja-Media

Ventajas vs. Alternativas (Hive Metastore): Serverless, integrado con Athena, sin coste adicional.

Costo: $0.00 (Free Tier)
Analogía: Es el índice de una biblioteca: sin él, no sabrías qué libros tienes.

Amazon Athena

Consultas SQL Serverless
RF-09: Modelo Analítico Tema 20: Arquitectura + Power BI
Concepto

Athena es un motor de consultas SQL serverless que lee directamente archivos en S3 (Parquet, CSV, JSON) usando los esquemas del Data Catalog. No hay clúster que administrar: se paga por cada TB escaneado, por lo que formatos columnares y particiones reducen el costo.

Rol clave: Es el motor de consultas analíticas. Lee la capa Gold desde S3 usando el Catálogo y devuelve los datos a QuickSight (o Power BI). Pagas solo por TB escaneado.

Importancia: Alta Complejidad: Baja

Ventajas vs. Alternativas (Redshift): Sin coste fijo de clúster inactivo. Para 0.2 TB/mes, cuesta $1.00.

Costo: $0.98/mes
Analogía: Es un buscador que lee libros en los estantes sin moverlos a una mesa.

Entorno de Pruebas

Capa 6: Security and Observability

AWS IAM

Identity and Access Management
RNF-06: Seguridad CT-02: Sin credenciales en repo Tema 5: AWS Fundamentos (IAM)
Concepto

IAM (Identity and Access Management) controla quién puede hacer qué sobre qué recursos en AWS, mediante usuarios, roles y políticas JSON. El principio de privilegio mínimo consiste en dar a cada identidad solo los permisos estrictamente necesarios para su tarea.

Rol clave: Es el guardia de seguridad. Define roles de privilegio mínimo: Lambda solo escribe en S3 Bronze, Spark lee S3 y escribe en RDS, etc. Evita accesos no autorizados.

Importancia: Crítica Complejidad: Media

Ventajas vs. Alternativas (Okta): Gratuito, nativo, sin mantenimiento. Esencial para la auditoría (CA-10).

Costo: $0.00
Analogía: Es el sistema de tarjetas de acceso: cada empleado solo entra a su oficina.

AWS KMS

Key Management Service
RNF-06: Datos cifrados Tema 5: AWS Fundamentos
Concepto

KMS (Key Management Service) crea y custodia claves criptográficas que otros servicios usan para cifrar datos en reposo. Usa cifrado de sobre (envelope encryption): los datos se cifran con una clave de datos, y esa clave se cifra a su vez con la clave maestra que nunca sale de KMS.

Rol clave: Es el cerrajero. Cifra datos en reposo en S3, RDS y Secrets Manager. Garantiza que si alguien roba un disco físico, no pueda leer los datos.

Importancia: Alta Complejidad: Baja

Ventajas vs. Alternativas (Cifrado manual): Rotación automática de claves, integración con CloudTrail.

Costo: $2.00/mes
Analogía: Es la caja fuerte donde se guardan las llaves de la empresa.

AWS Secrets Manager

Gestión de Credenciales
CT-02: Sin secretos en repo Tema 5: AWS Fundamentos
Concepto

Secrets Manager almacena de forma cifrada credenciales (contraseñas de bases de datos, API keys, tokens) y las entrega a las aplicaciones en tiempo de ejecución mediante una llamada autorizada por IAM. Puede rotarlas automáticamente sin cambiar el código.

Rol clave: Es el guardián de las contraseñas. Guarda credenciales de RDS, RabbitMQ y APIs fuera del código fuente. FastAPI y Airflow las leen en tiempo de ejecución.

Importancia: Alta Complejidad: Baja

Ventajas vs. Alternativas (Variables de entorno): Rotación automática, evita fugas de secretos en Git.

Costo: $3.20/mes
Analogía: Es la caja de seguridad donde se guardan las llaves, no debajo del felpudo.

Amazon CloudWatch

Monitoreo y Alarmas
RNF-01: Latencia CT-09: Alarma en vivo Tema 20: Observabilidad
Concepto

La observabilidad es la capacidad de entender qué ocurre dentro de un sistema a partir de sus salidas: logs (eventos), métricas (valores numéricos en el tiempo) y trazas. CloudWatch centraliza logs y métricas de AWS y dispara alarmas cuando una métrica cruza un umbral, por ejemplo la latencia p95.

Rol clave: Es el sistema de observabilidad. Recopila logs de Lambda, Airflow, Spark y FastAPI. Monitorea la latencia p95 y dispara alarmas si el Consumer se detiene o si la API supera los 250ms.

Importancia: Alta Complejidad: Baja-Media

Ventajas vs. Alternativas (Datadog): Nativo de AWS, sin coste de integración.

Costo: $11.09/mes (20 GB de logs, 10 alarmas)
Analogía: Son las cámaras de seguridad y el sistema de alarmas de la empresa.

AWS CloudTrail

Auditoría
RNF-06: Auditoría Tema 5: AWS Fundamentos
Concepto

CloudTrail registra cada llamada a la API de AWS en la cuenta: quién la hizo, desde dónde, cuándo y sobre qué recurso. Es el rastro de auditoría para seguridad y cumplimiento, y permite investigar cambios no autorizados en la infraestructura.

Rol clave: Es el registro notarial. Guarda un historial de quién hizo qué en la cuenta AWS (quién creó un bucket, quién modificó un rol IAM). Esencial para cumplimiento y seguridad.

Importancia: Alta Complejidad: Baja
